TP Integrador — Node & Express

Este archivo se sirve como contenido estático mediante express.static(). El proyecto se construye en tres partes: servidor y archivos planos (Módulo 6), base de datos MySQL con SQL manual y ORM (Módulo 7), y API con autenticación (Módulo 8).

Módulo 6

  • GET / — esta página (HTML)
  • GET /status — estado del servidor (JSON)

Módulo 7 — SQL manual (mysql2)

  • GET /usuarios — lista de usuarios (admite ?nombre=, ?page= y ?limit=)
  • PUT /usuarios/:id — actualiza nombre y/o email
  • DELETE /usuarios/:id — elimina un usuario
  • POST /usuarios/registro-transaccional — registra usuario + pedido en una transacción
  • GET /pedidos, POST /pedidos, PUT /pedidos/:id, DELETE /pedidos/:id — CRUD de pedidos

Módulo 7 — ORM (Sequelize)

  • GET /usuarios-orm — lista de usuarios con el ORM
  • GET /usuarios-orm/:id/pedidos — usuario con sus pedidos (relación 1:N con include)
