TP Integrador — Node & Express

Este archivo se sirve como contenido estático mediante express.static(). El proyecto se construyó en tres partes: servidor y archivos planos (Módulo 6), base de datos MySQL con SQL manual y ORM (Módulo 7), y API RESTful con autenticación JWT y subida de archivos (Módulo 8).

📄 Documentación interactiva de la API: /api-docs (Swagger). Las rutas marcadas con 🔒 requieren el token que entrega POST /login.

Autenticación (Módulo 8)

  • POST /registro — crea una cuenta
  • POST /login — devuelve un JWT
  • GET /perfil 🔒 — datos del usuario autenticado y su foto
  • POST /upload 🔒 — sube una foto de perfil (JPG, PNG o WEBP, máx. 2 MB)

Productos (Módulo 8)

  • GET /productos — lista (admite ?nombre= y ?precioMax=)
  • GET /productos/:id — un producto
  • POST /productos, PUT /productos/:id, DELETE /productos/:id 🔒

Usuarios y pedidos (Módulo 7)

  • GET /usuarios — lista (admite ?nombre=, ?page= y ?limit=)
  • PUT /usuarios/:id, DELETE /usuarios/:id 🔒
  • POST /usuarios/registro-transaccional 🔒 — usuario + pedido en una transacción
  • GET /pedidos — lista (admite ?usuarioId=)
  • POST /pedidos, PUT /pedidos/:id, DELETE /pedidos/:id 🔒
  • GET /pedidos/:id/productos — productos de un pedido (relación N:M)
  • POST /pedidos/:id/productos 🔒 — agrega un producto a un pedido
  • GET /usuarios-orm y GET /usuarios-orm/:id/pedidos — consultas con el ORM (relación 1:N)

Servidor (Módulo 6)

  • GET / — esta página (HTML)
  • GET /status — estado del servidor (JSON)
